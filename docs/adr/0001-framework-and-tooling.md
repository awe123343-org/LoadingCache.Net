# ADR-0001: .NET 8 baseline and development tooling

Accepted, 12 September 2026.

Core produces one `net8.0` asset. There is no framework-specific implementation justifying a duplicate net10 asset. Tests and source consumers target `net8.0;net10.0` and must execute on their actual runtimes. The repository pins SDK 10.0.100 and C# 12; that development requirement does not raise the consumer runtime minimum or claim the solution builds with SDK 8.

Updated 23 September 2026 at maintainer request: tests use TUnit 1.69.0 on Microsoft.Testing.Platform, selected by SDK 10 in `global.json`. Each test case (including argument rows and matrix combinations) runs independently with a fresh instance and parallel scheduling. Core keeps `max(2, ProcessorCount)` concurrent cases: the 4x CPU default caused ten gate/watchdog failures on .NET 8, while CPU-sized concurrency passed all 747 cases. CLI/environment concurrency overrides remain available. The previous framework, adapter and VSTest SDK dependencies are removed. Test projects use TUnit's generated entry point and FluentAssertions 8.11.0 assertions. Allocation measurements live in an independent executable referencing FluentAssertions without a test runner, so process-wide GC controls cannot affect concurrent tests. Test cancellation is injected explicitly. All projects retain C# 12; the production library remains net8.0. Synchronous assertions preserve callback and GC-lifetime semantics; asynchronous exception assertions are awaited. Exact exception, cancellation, single-flight, ownership and shutdown assertions remain required. No compatibility shim is retained.

FluentAssertions was upgraded to 8.11.0 on 19 September 2026 with explicit maintainer approval. It is used only to test this open-source project under the Xceed Community licence, rather than Apache-2.0. All references are private development dependencies; neither published package references or redistributes it. The Renovate major-version restriction remains removed. See the [upstream licence](https://github.com/fluentassertions/fluentassertions/blob/9ed9dc02c47e6ad6bb0b00401fe8ab21b6fd60eb/LICENSE).

CSharpier 1.3.0 is pinned in `.config/dotnet-tools.json`; use `dotnet tool restore` and `dotnet csharpier format/check .`. Its .NET 10 tool runtime affects development only. Published dependency metadata, frameworks, hashes and licences are recorded in [dependency evidence](../dependency-evidence.json); direct-package review does not replace transitive/security review.

The support table consulted on 12 September 2026 listed .NET 8 end of support as 10 November 2026 and .NET 10 as 14 November 2028. Retain the requested .NET 8 minimum unless an explicit compatibility policy changes it. Reassess servicing and migration before releases; distinguish Microsoft runtime support from library binary compatibility. [Official support policy](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core).
