# Feature and combination matrix

Implemented capabilities and release qualification are different. All engine features below remain within the 1.0 target; [release readiness](release-readiness.md) records current evidence and open gates. Historical test totals are not additive coverage claims.

| Capability                                   | Implementation and principal verification                                                                                                                                                                                            |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Four sync/async manual/loading personalities | Shared CacheEngine; genuine synchronous factories, fixed loading or per-call async factories. Personality/contract/consumer tests.                                                                                                   |
| Atomic loading and publication               | Exact entry/epoch/revisions, helper start, independent cancellation, retry and opt-in admission. Controlled publication/finalisation/reentrancy tests.                                                                               |
| Bulk lookup/mutation and true loading        | Bounded comparer-deduplicated snapshots, per-key commits/promises, bulk backend capability, fenced extras. Bulk loading/adversarial/terminal/revision tests.                                                                         |
| Adaptive Window TinyLFU                      | Window/probation/protected, packed four-bit sketch, ageing, admission jitter and reactive adaptation. Tiny/weighted policy tests and simulator; not current-master density-controller parity.                                        |
| Size and weight                              | Mutually exclusive maxima, immutable version weight, separate zero-weight resident cap, runtime resize. Policy/weight-publication/runtime-policy tests.                                                                              |
| Read/write maintenance                       | Lossy CAS stripes; reliable 256-event write queue; coalesced single-owner scheduling with rejection/full/exit fallback. Transport/integration/shutdown/ownership tests.                                                              |
| Expiration                                   | TTL+TTI or variable create/update/read expiry, monotonic time, hierarchical TimerWheel, optional prompt scheduler and cleanup. Fake-time/boundary/wrap/budget/stale-arm tests.                                                       |
| Refresh and timeout                          | Request-triggered reload(old value), explicit refresh, coalescing/backoff, hard-expired joining, owned deadlines and late-result fencing. Refresh/timeout/adversarial/finalisation tests.                                            |
| Weak references                              | Identity weak keys; synchronous weak values; collected cleanup without temporary lookup wrappers. GC/lifetime/refresh/composition tests.                                                                                             |
| Listeners                                    | Reliable synchronous lock-external eviction, bounded asynchronous removal, explicit causes and shutdown-safe notification statistics. Rejection/throw/re-entry/slow/pressure tests.                                                  |
| Statistics and Metrics                       | Default-off bounded striped saturating counters, independent BCL observable Metrics, bounded labels. Arithmetic/event classification/cardinality tests; scalability remains workload-specific.                                       |
| Policy inspection                            | Enabled-only maximum/weight/duration/age/variable expiry views; bounded approximate hot/cold copies; quiet lookup. Runtime-policy and concurrency tests.                                                                             |
| Mutable dictionary                           | Cache-aware views with conditional update/remove and retryable transforms; no blocking pending-task reads. Dictionary/ABA/callback tests.                                                                                            |
| Memory pressure                              | Opt-in latest-GC/source sampling, bounded version-fenced cold trimming. Fake-time/overlap/provider-error tests; no OOM guarantee.                                                                                                    |
| Owned values                                 | Separate manual OwnedCache with identity aliases, caller leases and bounded disposal backlog. Ownership/rejection/retention tests; no raw-value auto-disposal.                                                                       |
| Hosting                                      | Separate DI package, typed/keyed named singleton registration, options validation and ASP.NET Core/gRPC/Worker examples. DI/host/source consumers.                                                                                   |
| Packaging                                    | One net8.0 asset usable on .NET 8/10, XML docs, API baseline, deterministic symbols/Source Link configuration, real package consumers. Hosted managed publishing is active; Source Link retrieval/1.0 freeze remain distinct checks. |
| AOT/trim                                     | Analyzers and real core/DI smoke publish+run on qualified configurations; not inferred support for every RID.                                                                                                                        |
| Simulator/benchmarks/stress                  | LRU/SLRU/fixed/adaptive/BitFaster traces, Caffeine/MemoryCache/Guava comparisons, actual latency harness, controlled races and endurance. Evidence is source/platform/workload-specific.                                             |
| Provenance/security/release                  | Pinned source/test/licence map and notices. Complete legal/security/API/1.0 sign-off is not inferred from feature availability.                                                                                                      |

## Construction-time combinations

| Combination                                | Contract                                                                                                                            |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| No MaxConcurrentLoads                      | Supported for all personalities; omitted/null means no configured loader bound.                                                     |
| Explicit concurrent/pending limits         | Positive values; new work rejects at capacity while hits/joins remain available.                                                    |
| True bulk without C                        | Supported with explicit positive F/K, K≤F.                                                                                          |
| Exactly one size/weight maximum            | Required. Weight additionally needs a weigher and resident-count cap; size does not accept a weigher.                               |
| TTL + TTI                                  | Supported; either expiry makes a miss.                                                                                              |
| Variable + fixed TTL/TTI                   | Illegal: competing deadline owners.                                                                                                 |
| Refresh + fixed or variable expiry         | Supported in loading personalities; failure cannot extend hard expiry.                                                              |
| Refresh + manual personality               | Illegal without a fixed loader/reloader.                                                                                            |
| Strong keys + custom comparer              | Supported with stable, pure, thread-safe, non-reentrant equality.                                                                   |
| Weak keys + value type/custom comparer     | Illegal; reference identity only.                                                                                                   |
| Weak values + value type/async personality | Illegal; async shared tasks root results. Sync weak values remain supported.                                                        |
| No bulk capability                         | Supported single-key fallback; no exception-based capability guessing.                                                              |
| Scheduler/listeners + any personality      | Supported with explicit lifecycle and non-cooperative user-work limits.                                                             |
| Owned value mode                           | Manual lease API with size/weight/fixed expiry/scheduler/pressure/stats. Loading/bulk/variable/weak lease APIs are not implemented. |
| String configuration parser                | Optional and not exposed; typed builder/options are the selected configuration API.                                                 |
| JVM soft values                            | Intentionally unsupported; separately named memory-pressure eviction is available.                                                  |
| CacheWriter                                | Not a parity target: removed in Caffeine 3.x.                                                                                       |
| Distributed/L2/backplane/persistence       | Outside this local cache product.                                                                                                   |

Undocumented combinations must be validated or explicitly specified, never silently ignored. See [acceptance matrix](acceptance-matrix.md) for required race/feature coverage and [Caffeine differences](caffeine-differences.md) for intentional semantic differences.
